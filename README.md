# Drum-kit-mini-project

# Drum Kit Mini Project

A fun and interactive Drum Kit application created using HTML, CSS, and JavaScript.

## Features
- Play drum sounds using mouse clicks
- Play drum sounds using keyboard keys
- Real-time audio feedback
- Responsive and user-friendly interface
- DOM manipulation and event handling

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)

## Learning Outcomes
- Working with the DOM
- Handling keyboard and mouse events
- Using JavaScript Audio objects
- Creating interactive web applications
- Managing project files and assets

## How to Run
1. Download or clone the repository.
2. Open `index.html` in your browser.
3. Click the drum buttons or press the corresponding keys to play sounds.
